# Java OOP Lab

Laboratório prático de aprendizado criado para consolidar e aumentar o nível da Programação Orientada a Objetos em Java por meio de problemas progressivos.

## Objetivos de aprendizado

- Encapsulamento
- Composição
- Relacionamento entre objetos
- Separação de responsabilidades
- Interfaces
- Polimorfismo
- Exceções personalizadas
- Coleções
- Testes automatizados

## Primeiro módulo

Sistema de pedidos de restaurante desenvolvido em Java puro.

## Tecnologias

- Java 21
- Maven
- JUnit 5
- Git e GitHub
